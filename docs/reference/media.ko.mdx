# Media

`Media`는 CSS media query match에 따라 children을 렌더링합니다. render prop이면 `matches` boolean을 받고, 아니면 query가 match할 때 `children`, 아닐 때 `fallback`을 렌더링합니다.

```tsx lineNumbers
import { Media } from '@ilokesto/utilinent';

<Media query="(min-width: 768px)">{(matches) => matches ? <Desktop /> : <Mobile />}</Media>

<Media query="(min-width: 768px)" fallback={<MobileNav />}><DesktopNav /></Media>
```

## 프로퍼티

| Prop | Type | 설명 |
| --- | --- | --- |
| `query` | `string` | CSS media query 문자열입니다. |
| `children` | `ReactNode \| (matches) => ReactNode` | content 또는 render prop입니다. |
| `fallback` | `ReactNode` | query가 match하지 않을 때 렌더링됩니다(render prop 미사용 시). 기본값은 `null`입니다. |

## SSR

서버 렌더링과 클라이언트의 첫 hydration 렌더에서 `Media`는 match하지 않는 분기를 렌더링합니다. render prop 미사용 시 `fallback`, render prop 사용 시 `false`에 대한 결과입니다. 첫 페인트 전에 동기적으로 match하는 분기로 전환하므로, 서버와 클라이언트의 media 상태가 달라도 hydration 불일치가 발생하지 않습니다.

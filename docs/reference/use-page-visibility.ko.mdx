# usePageVisibility

`usePageVisibility`는 `document.visibilityState`가 `"visible"`인지 반환합니다.
문서의 `visibilitychange` 이벤트가 발생하면 갱신됩니다. 이 API는 아직
릴리스되지 않았으며 현재 배포 버전에는 포함되어 있지 않습니다.

```tsx lineNumbers
import { usePageVisibility } from '@ilokesto/utilinent/hooks';

function VisibilityStatus() {
  const isVisible = usePageVisibility();
  return <p>{isVisible ? '표시 중' : '숨김 또는 초기 동기화 대기 중'}</p>;
}
```

## 시그니처

```ts
function usePageVisibility(): boolean;
```

인자를 받지 않습니다. `true`는 문서가 표시 중임을, `false`는 문서가 숨겨져
있거나 서버 및 첫 hydration 렌더의 기본값을 사용 중임을 뜻합니다.
문서 가시성은 창의 포커스나 개별 요소의 화면 교차 여부와 다릅니다.

## SSR과 hydration

- 서버 렌더는 `document`에 접근하지 않고 `false`를 반환합니다.
- 첫 hydration 렌더도 탭이 표시 중인지와 관계없이 `false`를 반환하여 서버
  마크업과 일치합니다. 이후 React가 실제 문서 상태를 읽습니다.
- 클라이언트 전용 마운트는 현재 문서 상태를 즉시 읽습니다.
- 관련 없는 재렌더에서는 구독을 유지합니다. 마운트된 소비자마다 하나의
  리스너를 소유하며, 언마운트와 Strict Mode 정리 과정에서 제거합니다.

## 소비자의 선택적 작업 중단

훅은 상태만 제공합니다. 타이머, 폴링, 재시도, 데이터 캐시, 취소는 소비자가
관리합니다. 아래 예제에서는 컴포넌트가 직접 타이머를 만들고 정리하며,
훅이 작업을 실행하지 않습니다.

```tsx lineNumbers
import { useEffect, useState } from 'react';
import { usePageVisibility } from '@ilokesto/utilinent/hooks';

function VisibleCounter() {
  const isVisible = usePageVisibility();
  const [ticks, setTicks] = useState(0);

  useEffect(() => {
    if (!isVisible) {
      return;
    }
    const timer = window.setInterval(() => {
      setTicks((previous) => previous + 1);
    }, 1000);
    return () => window.clearInterval(timer);
  }, [isVisible]);

  return <output>{ticks}</output>;
}
```

브라우저에서 컴포넌트를 열고 다른 탭으로 전환한 뒤 돌아오세요. 숨겨져 있는
동안 카운터가 멈추고, 돌아오면 이전 값부터 다시 증가합니다. 놓친 횟수를
따라잡지는 않습니다. 언마운트하면 소비자의 타이머도 정리됩니다.
반환값이 바뀌었다고 다른 코드가 이미 시작한 작업이 자동으로 취소되는 것은
아닙니다. 그 정책은 소비자 이펙트의 정리 함수에서 구현하세요.

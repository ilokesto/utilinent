# useEventListener

`useEventListener`는 window/document/element target이나 ref에 DOM 이벤트 리스너를 연결합니다. handler는 ref에 보관되어 리스너가 재바인딩 없이 갱신됩니다.

```tsx lineNumbers
import { useEventListener } from '@ilokesto/utilinent/hooks';

function WindowSize() {
  useEventListener(window, 'resize', () => console.log('resized'));
  return null;
}
```

## Options

| Option | 설명 |
| --- | --- |
| `capture` | capture phase에서 리스닝합니다. |
| `passive` | passive 리스너입니다. |
| `disabled` | `true`면 리스너는 연결되지만 호출되지 않습니다. |
| `predicate` | handler 호출 전 실행되는 optional 필터입니다. |

target은 `window`, `document`, `EventTarget`, 또는 `React.RefObject`가 될 수 있습니다. SSR-safe: effect는 서버에서 실행되지 않습니다.

## Ref target

`target`이 `React.RefObject`이면 훅은 ref가 현재 가리키는 DOM 노드를 따라갑니다.

- 초기 렌더 이후 노드가 마운트되면 노드가 나타난 시점에 리스너가 연결됩니다.
- ref가 다른 노드로 교체되면 리스너가 새 노드로 옮겨가고 이전 노드의 리스너는 제거됩니다.
- ref가 `null`로 바뀌면 이전 노드에서 리스너가 해제됩니다.

handler만 갱신될 때는 리스너를 재바인딩하지 않고 항상 최신 handler를 호출합니다. `capture`, `passive`, `disabled`가 변경되면 새 옵션으로 리스너를 다시 연결하고 이전 target을 정리합니다.

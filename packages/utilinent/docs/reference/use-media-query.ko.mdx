# useMediaQuery

`useMediaQuery`는 CSS media query를 구독하고 현재 match 여부를 반환합니다.

```tsx lineNumbers
import { useMediaQuery } from '@ilokesto/utilinent/hooks';

function Nav() {
  const isDesktop = useMediaQuery('(min-width: 768px)');
  return isDesktop ? <DesktopNav /> : <MobileNav />;
}
```

media query 문자열을 전달하면 match가 변경될 때 반환값이 반응적으로 갱신됩니다.

## SSR과 hydration

서버 렌더와 클라이언트의 첫 hydration 렌더는 같은 초기 스냅샷을 사용합니다. 훅은 `false`를 반환하고, 실제 match 여부는 첫 페인트 전에 layout effect에서 동기적으로 반영됩니다. 따라서 hydration 마크업은 절대 어긋나지 않습니다.

- 첫 클라이언트 렌더는 query가 이미 match하더라도 `false`를 반환하며, 실제 값은 브라우저가 페인트하기 전에 커밋됩니다.
- 서버와 클라이언트의 media 상태가 달라도 recoverable hydration error 없이 hydration이 완료됩니다.
- `query`를 바꾸면 새 query에 다시 구독하고 이전 change listener를 정리합니다.
- `window.matchMedia`를 사용할 수 없는 환경에서는 예외 없이 `false`를 유지합니다.
